# sdfr

Программный рендерер параметрической модели здания на C11 и NASM: raymarching
по полям расстояний (SDF) на CPU. Версия 0.1.0, в разработке.

## Сборка и запуск

Требуется x86-64 Linux или WSL 2.
Команды выполняются из корня репозитория.

```sh
sudo apt install -y build-essential
make
./sdfr
```

- `./sdfr` — выводится строка с версией 0.1.0.
